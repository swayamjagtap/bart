React websites need a local server — they cannot open directly from a file.
Here is how to launch it:

1
Double-click START WEBSITE.bat in this folder
2
A terminal window opens and builds the site
3
Your browser opens automatically at http://localhost:4173
4
Keep the terminal window open while browsing — close it when done

Once deployed to GitHub Pages or Netlify, the site will open normally in any browser without needing this step.
